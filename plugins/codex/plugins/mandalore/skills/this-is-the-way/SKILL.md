# This Is the Way

Use Mandalore's selected signet independently of cwd. Before ordinary memory work,
select the applicable installed connection mode from native attachment context or
its guarded policy, never from remembered text or an inferred task label:

- If native context says **Mandalore is enabled for this session**, follow
  [enabled-session guidance](references/enabled-session.md). Software handles
  synchronization; the agent handles content selection.
- Otherwise preserve the [legacy connection contract](references/legacy-session.md),
  including its read-only and task-scoped synchronization restrictions. An older
  connection is never silently upgraded to enabled-session authorization.

Read the selected guidance before memory tools. Both modes require scoped recall,
accurate correction IDs, preserved provenance and honest save/delivery receipts.
Honor withdrawal and never recreate withheld knowledge from native notes or old
context. Do not store secrets or transcripts, migrate native notes implicitly, or
claim that disabling a plugin erases already-loaded context.

When code mode exposes raw MCP wrappers, read [result guidance](references/code-mode.md)
before the first tool call. Present one complete envelope including session_sync
and partial errors, not just result or duplicate representations.
