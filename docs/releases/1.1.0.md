# Mandalore 1.1.0

[v1.1.0](https://github.com/acoz-labs/mandalore/releases/tag/v1.1.0) was published
September 17, 2026 from the exact owner-accepted retained artifact. No product
rebuild, memory migration or personal-installation update occurred at publication.

## Included changes

- Native Pi connection, memory skills, lifecycle handling and Codex/Pi continuity.
- One faithful model-visible MCP result, including errors and source provenance.
- Explicit remember/journal-and-sync operations and consolidation delivery without
  filler writes, while respecting task-specific saving and syncing restrictions.
- Progressive historical-reference excerpts, deliberate continuation and full
  review when requested; source pins and current-versus-historical distinctions.
- Non-executing Armorer readiness assessment and explicit native-check handoff.
- Lower anonymous release request overhead and bounded quota/recovery guidance.
- Corrected first-use Codex profile setup and plain-prompt cancellation.

Signet and shared protocol formats remain version 1. Existing local-only save
operations retain their defaults. Native verification covers macOS arm64,
Codex 0.154.0 and Pi 0.85.1 with Node 24.1.0. Other binaries are cross-built,
not equivalent native verification. Pi declares Node 22.19.0 or newer.

## Install and update

Follow the [review-before-running bootstrap](../../README.md#install), or use an
existing Mandalore CLI's installation menu to select 1.1.0. Review the prefix and
effects before confirming. CLI installation and native Codex/Pi connection updates
are separate actions; start fresh native sessions after connection changes.
No shell/PATH, credential enrollment or memory import is automatic.

For a manual download, obtain the platform executable and SHA256SUMS from the
same versioned release, compare its SHA-256 with the single matching checksum
entry before execution, and run `release install --version 1.1.0 --prefix DIR`.
This checks official-release bytes, not an independent signing authority.
Public discovery remains subject to anonymous GitHub quota; inspect timing and
explicitly retry when appropriate. Never substitute an unverified download.

Keep owned older generations for explicit rollback. Accepted-candidate evidence
covers isolated 1.0.0 to 1.1.0 update, partial recovery, rollback and re-upgrade;
publication does not repeat every model scenario. Do not use binary rollback as
permission to downgrade an incompatible future memory schema.

## Limits and deferred work

Smaller initial retrieval and fewer memory calls do not guarantee smaller total
model context. Full requested reviews still read all relevant material. The
matched retrieval runs had nearly equal whole-task input; the evidence separates
excerpt bytes, MCP envelopes and native model tokens.

Ordinary learning and agent-selected save-and-sync work without a special phrase.
Deterministic compaction/end-of-session delivery remains #55 work. Export #80,
withdrawal #81, narrow recovery-command copyability #77 and Claude Code #14 remain
separate work. The original CI-trigger root cause in #19 remains unproven and
does not block this verified release. No screen-reader, non-host-native or
universal model-reliability claim is made.
