# Decision

Selected: a small skill with an on-demand administrative reference and generated local connection context. Existing operations remain the enforcement and schema source.

Rejected: a larger administration MCP surface (unnecessary context), an autonomous repair loop (broader authority/state), or guessing state from cwd/PATH (wrong bank risk).

Keep doctor command and connection_doctor JSON operation stable; make armorer the documented human name. No new memory schema, credentials, synchronization hooks or dependencies. Source plugin version remains development metadata; existing deterministic connection generations and release stamping refresh caches without editing a user's marketplace.
