# Solution Decision

Select validated portable visibility events behind a mandatory new bank format.
Reject extension flags, sensitivity labels and fabricated corrections: old readers
can ignore their intended meaning. Reject machine-local suppression because it
does not travel with memory. Reject deletion/history rewriting as a different,
unauthorized promise. The owner selected same-bank continuity rather than a
second imported bank.

Keep old evidence immutable. Format2 permits preserved legacy objects; newly
written content carries explicit causal visibility references. A separate
visibility graph records withdraw/restore actions, expected content heads,
visibility parents, authorship and reason. All graphs validate before disclosure.

Withdrawn, conflicting or causally unreviewed states are withheld from ordinary
recall. A unique restore covers content it observed or later content whose writer
observed that restore. Multiple restore heads remain a visibility conflict until
explicit resolution. Content conflicts remain content conflicts after restoration.
No clock chooses a winner. A missing dependency fails closed rather than becoming
an empty/default-visible state.

Retention is preview-only under explicit selection and policy. No default TTL,
destructive apply or automatic withdrawal. Journals and external references are
independent evidence and are described honestly, not guessed from record text.

One-time format upgrade requires deliberate preview/apply; ordinary memory use
never initiates it. Local activation, Git checkpoint and remote delivery are
separate outcomes. Production downgrade is not an automatic recovery mechanism.
