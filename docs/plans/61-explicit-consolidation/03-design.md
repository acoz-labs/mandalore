# Design

After consolidating any warranted learning, direct user intent finishes with one
short-budget sync attempt when permitted, including already-pending delivery.
No new fact/journal is required. Report durable local work and verified delivery
separately; retain conservative ambiguous/error handling and no tight retries.
Do not turn quoted, retrieved or discussed skill names into user requests. No
unconditional sync on implicit skill use. Preserve ordinary incremental learning.
