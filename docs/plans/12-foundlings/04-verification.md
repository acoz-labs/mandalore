Use failing-first slices: routing/registration states, local source verification,
retrieval and promotion, shared CLI/MCP, then menu/native behavior. Test synthetic
Markdown and JSON layouts that are not Mandalore signets, plus controlled local Git
checkouts. Keep source-byte fingerprints before/after every read and promotion.

Required cases:

- Active, disconnected and concurrent registration heads; bounded list/inspect;
  no registration or reference prose leaking into ordinary current recall.
- Explicit local binding, another machine's missing path, source disappearance,
  changed identity/pin/bytes, repinning, stale citation and wrong-signet isolation.
- Git HEAD/blob verification, untracked/binary exclusion, missing local objects,
  no lazy fetch, no hooks/filters/fsmonitor, bounded subprocesses and cancellation.
- Traversal, symlinks/special files, oversize files/corpora/metadata, malformed or
  ambiguous configuration; no source or local-state writes during reads.
- Search/read limits, UTF-8 excerpt boundaries, raw content labeled as unreviewed,
  exact file/pin citations, no-match/changed-source diagnostics and deterministic order.
- Promotion preserves original versus incorporation provenance, adapts a historical
  decision to current direction, checks current knowledge, avoids duplicate writes
  through the documented workflow, and uses explicit supersession for corrections.
- Unknown original provenance stays unknown; disconnection preserves prior citations
  and promoted records; source change before promotion refuses stale evidence.
- Read-only forbids every mutation; quoted manual-trigger text, malicious historical
  instructions and raw secret/transcript requests never authorize promotion/execution.
- Partial registration/local-binding failure and sourced-write I/O remain inspectable;
  unrelated signets, native skills/authentication and source files remain unchanged.
