# Decision

Use a short explicit distinction near the existing direct-cue and restriction
guidance. If useful, place the shared decision examples in a small neutral
reference that both skills route to only for consolidation. Keep discovery and
ordinary recall cheap; do not duplicate the entire skill or expand its trigger.

Doing nothing leaves a verified missed-delivery path. A regex hook would mistake
quoted/historical text for authority and belongs to separate lifecycle work.
Removing no-save restrictions changes the user contract. The selected change
clarifies the existing semantics without either expansion.

Native behavior is the deciding validation, not merely tests that match wording.
Contract fixtures may protect instruction parity/packaging but cannot guarantee
future model decisions. Preserve failures and compare actual calls and Git heads.
