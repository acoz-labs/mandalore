# Design

Keep the existing explicit cue, useful learning, companion-counting, bounded
three-second attempt, no filler, truthful delivery and no automatic retry rules.
Add a concise distinction: a statement that no new knowledge/journal is needed
does not itself forbid delivery of existing work. Explicit read-only/no-save/
no-sync direction for the task remains a prohibition. No-journal only limits
journaling; do not broaden it to all memory activity.

Align Codex and Pi's neutral instructions without copying harness-specific
result-rendering guidance. If a shared reference is introduced, package it in
both adapters and extend byte-parity/reference-resolution tests.

No server/API change, automatic hook, heuristic text parser or authorization
store. The host agent chooses permitted calls using the active user request.
Missing connection yields a concise limitation, no alternate bank or CLI fallback.
