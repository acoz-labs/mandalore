# Technical Design

Set VERSION to1.2.0 and add a durable candidate guide. Map all four delivery issues
and this preparation issue to explicit implementation PR references for nomination.
Explain old-updater refusal, verified-new-executable installation, stopped native
sessions, separate format activation, retained evidence/recovery and no downgrade.

Build once from reviewed main with required checks. Retain exact source/run/attempt,
artifact ID, archive digest, manifest digest and expiry. Independently verify
transport and all eight payloads. Nominate those same bytes with existing tooling.

Use synthetic banks, local bare remotes and designated native lab profiles. Never
copy credentials or personal memory. Evidence links exact executable/plugin hashes,
native versions, scenarios, original issue criteria and limitations. No agent-run
test substitutes for human product judgment. Any candidate defect returns to
implementation and requires a new candidate rather than replacing accepted bytes.
