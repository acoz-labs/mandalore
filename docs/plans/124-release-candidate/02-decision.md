# Solution Decision

Use minor version1.2.0 for additive operations and optional bank-format support.
Do not change shared protocol or force existing signets to upgrade. Keep source
package manifests as development placeholders, stamped by the existing builder.

Reuse the retained-candidate workflow and exact artifact identity. Reject local
rebuilding after acceptance, a mutable replacement1.1.0, blanket acceptance-policy
exceptions and automatic personal installation. No new runtime feature is needed.
