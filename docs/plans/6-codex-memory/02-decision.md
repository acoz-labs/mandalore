# Solution Decision

Prefer a thin plugin over injecting global AGENTS.md, creating a private
CODEX_HOME, or launching an assistant-specific agent wrapper. The latter paths
obscure inherited resources and native authentication ownership.

Use command hooks rather than MCP-tool startup hooks: the documented MCP startup
connection race makes a tiny local reader more predictable. Port the predecessor
bounded event decoder and scope-routing pattern, hardening malformed input and
failure output. Do not infer project scope from cwd or search unrelated project
records in an unscoped hook.

SessionStart provides orientation; UserPromptSubmit can add a small bank-wide
evidence packet and scope inventory. The skill selects specific scopes and reads
fresh local files. Sync runs only within authorized tasks, with a short budget,
and after useful saves; failed delivery must not discard local knowledge.

Do not use Stop/SessionEnd as a required save path: interruption and abnormal
exit cannot guarantee final capture. Do not use phrase matching to force saves;
quoted/retrieved content is evidence and no-write scope still applies.

Retain the supported compatibility package generated by plugin-creator rather
than maintain two manifest models at once. Keep reusable behavior in the Go
runtime and skill, so Pi/Claude adapters can follow later without a new bank.
