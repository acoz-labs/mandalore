testing pane. No real bank, hosting credentials or network write is needed for
the synthetic matrix. Inspect the installed Git feature/version before relying
on merge-tree; declare the minimum supported feature set in permanent docs.

- Explicit initialization/checkpoint and no-origin local-only receipt; repeat
  checkpoint is content-idempotent, no empty commit.

  committed changes and return pending with no raw secret canary output.

  concurrent unrelated appends, competing semantic revisions and journal evidence.

  symlinks/unsafe candidate content and real file conflicts never replace local work.

  files, staged/partially staged work, existing merge state and concurrent writer.

  bounded subprocess cleanup and conservative ambiguous outcome reporting.

  retain origin device/harness and correction reasons across clones.
- CLI/MCP expose the same real operations, outputs/errors and bounded budgets.
